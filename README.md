# 📝 NOTES SAVIOR - Smart Student Notes App

**NOTES SAVIOR** is a modern, secure, and user-friendly web application built with React.js and Firebase. It allows users to create, save, edit, search, and manage their notes seamlessly in the cloud.

🔗 **Live Project Link:** [https://student-notes-save-web.vercel.app/](https://student-notes-save-web.vercel.app/)

---

## ✨ Features

* 🌐 **Live Deployment:** Hosted and accessible online via Vercel.
* 🔐 **Authentication System:** Secure user Login and Registration (Account Creation) powered by Firebase Authentication.
* 📁 **Saved Notes Menu (Slide Drawer):** 
  * Sleek and responsive sliding navigation drawer.
  * **Hover Effects & Animations:** Interactive visual feedback and smooth transitions on hover.
  * **Interactive Selection:** Clicking any saved note instantly opens it in the main viewer panel and closes the menu.
* ➕ **Create & Edit Notes:** Easily create new notes or update existing ones at any time.
* 📖 **Full View Mode:** Clean, readable interface designed for comfortable reading.
* 🔍 **Real-time Search:** Filter and find notes instantly by searching titles or content.
* 🗑️ **Delete Notes:** Remove unwanted notes with a single click.
* 📱 **Responsive Dark UI:** Designed with a clean dark theme optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Hooks, Inline Dynamic Styling, Keyframe Animations)
* **Backend / Database:** Firebase Firestore (Cloud NoSQL Database)
* **Authentication:** Firebase Auth (Email & Password)
* **Hosting:** Vercel
* **Build Tool:** Vite / Create React App
